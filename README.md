# ContactsApp

## Описание проекта и выполненные требования
Данное Android-приложение разработано для управления телефонной книгой устройства с использованием языка Kotlin и фреймворка Jetpack Compose. В рамках тестового задания был выбран и полностью реализован третий вариант задания, который объединяет функционал просмотра списка контактов и их очистки от дубликатов. Приложение обеспечивает отображение реальных записей из телефонной книги устройства, предоставляет возможность совершения звонков по клику на контакт и реализует механизм поиска и удаления повторяющихся записей. 

Важным техническим требованием являлось вынесение логики удаления дубликатов в отдельный сервис, взаимодействующий с основным приложением через AIDL-интерфейс. По завершении операции пользователь получает уведомление о статусе выполнения задачи: успешное удаление, сообщение об ошибке или информирование об отсутствии дубликатов. Список контактов обновляется автоматически сразу после завершения работы сервиса, отражая актуальное состояние телефонной книги.

## Технический стек и архитектура
Проект построен на базе архитектуры MVVM в парадигме Clean Architecture, что обеспечивает четкое разделение ответственности между слоями представления, бизнес-логики и данных. Для управления асинхронными операциями и потоками данных используются Kotlin Coroutines и StateFlow, а навигация между экранами реализована через Jetpack Navigation Compose. Взаимодействие с системными данными телефона осуществляется посредством ContentResolver и ContactsContract API. Для запроса критически важных разрешений (чтение контактов, совершение звонков) применяется Activity Result API.

В кодовой базе применены следующие архитектурные паттерны: Repository Pattern для абстрагирования источников данных, Use Case (Interactor) для инкапсуляции конкретной бизнес-логики, Mapper Pattern для преобразования моделей между слоями и Factory Pattern для ручной передачи зависимостей в ViewModel. Интерфейс приложения реагирует на изменения состояния данных благодаря паттерну Observer, реализуемому через сбор состояний из Flow.

## Дизайн и пользовательский интерфейс
Визуальное оформление приложения разработано на основе макетов, созданных в Figma. Интерфейс спроектирован с использованием компонентов Material Design 3 и полностью написан на Jetpack Compose. В проекте активно используются Compose Previews (файлы с суффиксом Preview.kt), которые позволяют просматривать состояние компонентов, таких как экраны списка, карточки контактов и поля ввода, непосредственно в среде разработки Android Studio без необходимости запуска эмулятора. Это позволяет проверять различные сценарии отображения, включая темную тему, состояния загрузки и пустые списки.

Стоит отметить, что главный экран приложения (Dashboard) содержит элементы демонстрационного характера. Карточки быстрого доступа и блоки статистики на этом экране реализованы как UI-макеты, призванные показать архитектуру навигации и стиль интерфейса. Основной функциональный блок — список контактов и экран детальной информации — работает с реальными данными устройства.

## Логика работы приложения
Пользовательский сценарий начинается с запуска приложения и просмотра главного экрана. Переход к списку контактов инициирует загрузку данных из телефонной книги, которые группируются по алфавиту. Взаимодействие со списком реализовано следующим образом: нажатие на строку контакта сразу инициирует исходящий вызов на основной номер телефона. Нажатие на специальную иконку информации открывает отдельный экран с расширенными данными о контакте, включая адрес, email, компанию и заметки. 

Функция очистки от дубликатов доступна через кнопку в верхнем меню. При активации запускается фоновый процесс через AIDL-сервис, который анализирует записи и удаляет только те контакты, у которых полностью совпадают все заполненные поля. После завершения операции система выводит соответствующее уведомление, а список на экране автоматически перерисовывается, исключая удаленные записи.

## Инструкция по запуску и разрешения
Для запуска проекта необходимо открыть его в Android Studio и выполнить синхронизацию Gradle-файлов. Приложение совместимо с устройствами на базе Android 8.0 (API 26) и выше. При первом запуске система запросит необходимые разрешения: READ_CONTACTS для чтения базы данных контактов, WRITE_CONTACTS для возможности удаления записей и CALL_PHONE для инициирования прямых вызовов.
