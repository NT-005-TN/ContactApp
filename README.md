# Алгоритм выборки сотрудников по юбилеям стажа

## Описание
Программа обрабатывает список сотрудников и их стаж в днях. Для каждого работника вычисляется дата ближайшего юбилея (кратного 1000 дней). В итоговый отчёт попадают только те сотрудники, чей юбилей приходится на текущую календарную неделю (с понедельника по воскресенье).

## Соответствие требованиям
- Результат формируется в виде двумерного массива строк: первый элемент — дата (ДД.ММ), второй — строка в формате «Имя – X дней».
- Дата юбилея рассчитывается математически через формулу смещения, без циклического перебора.
- В методе main отсутствуют явные условные операторы. Вся фильтрация и преобразование данных реализованы через предикаты Stream API.
- Границы недели вычисляются динамически относительно заданной даты. Код совместим с заменой фиксированной даты на LocalDate.now().

## Запуск
Требуется Java 16+.
1. Скомпилировать файл: `javac Main.java`
2. Запустить: `java Main`

Дата в коде зафиксирована для воспроизводимости результатов при проверке. Вывод направляется в консоль в табличном формате. Пустые дни недели в результат не включаются.
